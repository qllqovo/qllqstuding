🚀 运动学与动力学 点击折叠
1. 匀变速直线运动核心公式
速度公式：v = v0 + at
位移公式：x = v0t + (1/2)·at2
速度位移公式：v2 - v02 = 2ax
💡 不涉及时间时，优先使用速度位移公式。
2. 牛顿第二定律
合力：F合 = m·a
💡 力与加速度同生同灭，方向永远一致。
3. 平抛运动
水平方向：x = v0·t ， vx = v0
竖直方向：y = (1/2)·g·t2 ， vy = g·t
⚡ 功、能与动量 点击折叠
1. 功与功率
功：W = F·x·cosθ
功率：P = W / t = F·v
2. 动能定理
合外力做功：W合 = Ek末 - Ek初
动能公式：Ek = (1/2)·m·v2
3. 动量定理
冲量等于动量变化：F合·t = m·v2 - m·v1
💡 动量是矢量，列式前必须先规定正方向！
🪐 万有引力与航天 点击折叠
1. 黄金代换公式
G·M = g·R2
💡 忽略自转时，星球表面重力等于万有引力。
2. 万有引力提供向心力
F万 = G·(M·m) / r2
等于：m·v2/r = m·ω2·r = m·(4π2/T2)·r
⚡ 静电场 点击折叠
1. 库仑定律
F = k·(q1·q2) / r2
2. 电场强度 (E)
定义式：E = F / q （适用于所有电场）
点电荷场强：E = k·Q / r2
匀强电场：E = U / d
🔋 磁场与电磁感应 点击折叠
1. 安培力与洛伦兹力
安培力：F = B·I·L （电流垂直于磁场）
洛伦兹力：F = q·v·B （速度垂直于磁场）
2. 法拉第电磁感应定律
感应电动势：E = n·(ΔΦ / Δt)
切割磁感线：E = B·L·v
💡 近代物理与光学 点击折叠
1. 光电效应方程
最大初动能：Ek = h·ν - W0
💡 W0 是逸出功，h 是普朗克常量，ν 是入射光频率。
2. 质能方程与折射率
质能方程：E = m·c2
折射率公式：n = c / v

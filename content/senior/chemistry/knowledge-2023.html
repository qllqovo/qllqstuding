一 · 常见元素化合价 +
  • 碱金属元素、Ag、H：+1；F：−1
  • Ca、Mg、Ba、Zn：+2；Cl：−1、+1、+5、+7
  • Cu：+1、+2；O：−2
  • Fe：+2、+3；S：−2、+4、+6
  • Al：+3；P：−3、+3、+5
  • Mn：+2、+4、+6、+7；N：−3、+2、+4、+5
二 · 氧化还原反应 +

定义：有电子转移（或化合价升降）的反应；本质：电子转移（得失与偏移）；特征：化合价升降。

氧化剂（具氧化性）→ 得电子 → 化合价下降 → 被还原 → 还原产物；
还原剂（具还原性）→ 失电子 → 化合价上升 → 被氧化 → 氧化产物。

口诀：得—降—（被）还原—氧化剂；失—升—（被）氧化—还原剂。

三 · 金属活动性顺序 +

K Ca Na Mg Al Zn Fe Sn Pb (H) Cu Hg Ag Pt Au

从左到右还原性逐渐减弱，与酸（水）反应越来越困难。

四 · 离子反应与离子共存 +

电解质：在水溶液中或熔融状态下能导电的化合物；反之为非电解质。

离子方程式书写四步：

  1. 写：写出化学方程式；
  2. 拆：易溶、易电离物质拆成离子；难溶（CaCO₃、BaSO₄、AgCl、Mg(OH)₂ 等）、难电离（H₂CO₃、CH₃COOH、HClO、H₂O 等）、气体、氧化物不拆；
  3. 删：删去两边都有的离子；
  4. 查：检查原子个数与电荷是否守恒。

离子不能共存的四种情况：生成沉淀（Ba²⁺ 与 SO₄²⁻）；生成弱电解质（H⁺ 与 CH₃COO⁻）；生成气体（H⁺ 与 CO₃²⁻）；发生氧化还原反应（H⁺、NO₃⁻ 与 Fe²⁺）。

五 · 放热反应与吸热反应 +

化学反应一定伴随能量变化。反应物总能量大于生成物时为放热反应，反之为吸热反应。

常见放热：燃烧、酸碱中和、活泼金属与酸的置换反应。

常见吸热：Ba(OH)₂·8H₂O 与 NH₄Cl 反应、灼热碳与 CO₂ 反应、C/CO/H₂ 还原 CuO。

六 · 物质的量与化学计量 +

阿伏加德罗常数 \(N_A\approx6.02\times10^{23}\,\text{mol}^{-1}\)（0.012 kg ¹²C 所含碳原子数）。

\[ n=\frac{N}{N_A}=\frac{m}{M} \]

气体（标准状况 \(V_m=22.4\,\text{L/mol}\)）：\(n=\dfrac{V}{V_m}\)；同温同压下 \(\dfrac{V_A}{V_B}=\dfrac{n_A}{n_B}\)。

溶液浓度：\(C=\dfrac{n}{V}\)；与质量分数换算 \(C=\dfrac{1000\rho\,\omega}{M}\)。

七 · 一定物质的量浓度溶液的配制 +

计算 → 称量（天平 / 滴定管）→ 溶解 → 检漏 → 移液 → 洗涤 2~3 次 → 定容（凹液面与刻度线相切）→ 摇匀 → 装瓶贴标签。

必备仪器：天平、量筒或滴定管、烧杯、玻璃棒、容量瓶、胶头滴管。

八 · 铁及其化合物 +

银白色、能被磁铁吸引，地壳含量仅次于氧、硅、铝。

与非金属：Fe+S → FeS；3Fe+2O₂ → Fe₃O₄；2Fe+3Cl₂ → 2FeCl₃。
与水蒸气：3Fe+4H₂O(g) → Fe₃O₄+4H₂；与非氧化性酸：Fe+2H⁺ → Fe²⁺+H₂↑。

Fe²⁺ 检验：浅绿色；与 KSCN 不显红色，滴氯水后变红；加 NaOH 出现白色→灰绿→红褐沉淀。

Fe³⁺ 检验：黄色或棕黄色；与 KSCN 显红色；加 NaOH 产生红褐色沉淀。

九 · 硅及其化合物 +

晶体硅是良好半导体材料，可制光电池。SiO₂ 熔点高、硬度大，是酸性氧化物但不溶于水，用于制造光导纤维。

SiO₂+2NaOH → Na₂SiO₃+H₂O；SiO₂+4HF → SiF₄↑+2H₂O。

水玻璃（Na₂SiO₃ 水溶液）可作粘合剂、防腐剂；空气中变质：Na₂SiO₃+CO₂+H₂O → H₂SiO₃↓+Na₂CO₃。

硅酸盐常用氧化物形式表示，如滑石 Mg₃(Si₄O₁₀)(OH)₂ 写作 3MgO·4SiO₂·H₂O。

十 · 氯、溴、碘 +

氯气黄绿色、密度比空气大、有毒。Cl₂+H₂O → HCl+HClO；新制氯水含 Cl₂、HClO、H⁺、Cl⁻、ClO⁻ 等。

次氯酸 HClO 是强氧化性弱酸，可杀菌、消毒、漂白；漂白粉有效成分为 Ca(ClO)₂。

溴为深红棕色易挥发液体，碘为紫黑色易升华固体；氧化性顺序：Cl₂ ＞ Br₂ ＞ I₂。

十一 · 硫及其化合物 +

SO₂ 无色有刺激性气味，是酸性氧化物，具暂时漂白性与还原性：SO₂+Cl₂+2H₂O → H₂SO₄+2HCl。

浓硫酸三大特性：吸水性（干燥剂）、脱水性、强氧化性（使 Fe、Al 钝化）；Cu+2H₂SO₄(浓) → CuSO₄+SO₂↑+2H₂O。

pH 小于 5.6 的降水称酸雨，防治需脱硫、开发新能源。

十二 · 氮及其化合物 +

N₂ 分子含 N≡N，性质稳定。N₂+O₂ → 2NO；2NO+O₂ → 2NO₂；3NO₂+H₂O → 2HNO₃+NO。

NH₃ 极易溶于水（1:700），水溶液显碱性；与 HCl 产生白烟。实验室用 2NH₄Cl+Ca(OH)₂ → 2NH₃↑+CaCl₂+2H₂O 制备，向下排空气法收集，碱石灰干燥。

铵盐检验：NH₄⁺+OH⁻ → NH₃↑+H₂O，湿润红色石蕊试纸变蓝。硝酸不稳定：4HNO₃ → 4NO₂↑+O₂↑+2H₂O；王水为浓盐酸与浓硝酸体积比 3:1。

十三 · 周期表、周期律与化学键 +

质子数 = 原子序数 = 核电荷数 = 核外电子数；质量数 \(A=Z+N\)。同位素质子数相同、中子数不同。

同周期从左到右非金属性增强、原子半径减小；同主族从上到下金属性增强。非金属性最强为 F，自然界金属性最强为 Cs。

非极性键（同种原子，如 H—H）、极性键（不同原子，如 H—Cl）；离子键多存在于活泼金属与非金属之间，AlCl₃ 是共价化合物。

附 · 常用反应方程式速查 +
氧化 / 还原性反应 +
  • 2F₂+2H₂O → 4HF+O₂；Cl₂+2NaBr → 2NaCl+Br₂；Cl₂+2NaI → 2NaCl+I₂
  • S+O₂ → SO₂；N₂+O₂ → 2NO；C+CO₂ → 2CO
  • Cl₂+SO₂+2H₂O → H₂SO₄+2HCl；2O₂+3Fe → Fe₃O₄
歧化与中和反应 +
  • Cl₂+H₂O → HCl+HClO；Cl₂+2NaOH → NaCl+NaClO+H₂O
  • 2Cl₂+2Ca(OH)₂ → CaCl₂+Ca(ClO)₂+2H₂O
  • 3S+6NaOH → 2Na₂S+Na₂SO₃+3H₂O

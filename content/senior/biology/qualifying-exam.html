一、细胞的分子组成 +

（一）生物大分子以碳链为骨架

1. 组成生物体的主要化学元素种类及其重要作用（A）

（1）常见元素的分类：

  • 大量元素：C、H、O、N、P、S、K、Ca、Mg 等；
  • 微量元素：Fe、B、Mn、Cu、Zn、Mo 等；
  • 最基本的元素：C——原因是生物大分子以碳链为基本骨架；
  • 活细胞中含量最多的元素：O。

（2）存在形式和作用：大多以化合物的形式存在，其中 C、H、O、N 含量丰富，是构成细胞中主要化合物的基础。

（3）生物界与非生物界的统一性与差异性：

  • 统一性：构成生物体的元素在无机自然界都可以找到，没有一种是细胞和生物所特有的；
  • 差异性：生物界和非生物界相比，同种元素的含量存在差别。

（二）水和无机盐的作用

1. 水在细胞中的存在形式与作用（A）

  • 含量：是活细胞中含量最多的化合物；
  • 结合水：是细胞结构的重要组成成分；
  • 自由水：是细胞内的良好溶剂；参与细胞内许多生物化学反应；运输营养物质和代谢废物；提供细胞内发生各种化学反应的液体环境。

说明：自由水与细胞新陈代谢强度有关，代谢旺盛的细胞自由水含量一般较多；结合水与细胞抗逆性（植物抵抗外界不良环境的能力）有关，休眠的种子、越冬的植物、生活在干旱和盐渍条件下的植物，结合水含量一般较多。

2. 无机盐在细胞中的存在形式与作用（A）

  • 存在形式：大多以离子形式存在；
  • 有些无机盐是细胞内某些复杂化合物的组成成分，如 Fe²⁺ 是构成血红蛋白的成分、Mg²⁺ 是构成叶绿素的成分、I 是构成甲状腺激素的成分；
  • 多数无机盐对维持细胞和生物体的生命活动有重要作用，如缺少 Ca²⁺ 时哺乳动物会出现肌肉抽搐现象；
  • 维持细胞的酸碱平衡，如 CO₃²⁻ / HCO₃⁻ 等缓冲物质；
  • 维持细胞的渗透压，如 Na⁺、Cl⁻ 对维持细胞外液渗透压具有重要作用。

（三）蛋白质的结构与功能

1. 氨基酸的结构与脱水缩合（B）

  • 元素组成：除 C、H、O、N 外，可能还含有 S 等；
  • 结构通式：
\[ \mathrm{H_2N-\underset{\underset{H}{|}}{\overset{\overset{R}{|}}{C}}-COOH} \]
  • 种类：约 20 种，取决于 R 基；
  • 判断依据：至少有一个氨基和一个羧基连接在同一个碳原子上；
  • 脱水缩合：一个氨基酸分子的羧基和另一个氨基酸分子的氨基相连接，同时脱去一分子水，连接两个氨基酸的化学键叫肽键。
\[ \mathrm{H_2N{-}CHR_1{-}COOH+H_2N{-}CHR_2{-}COOH} \xrightarrow{\text{酶}} \mathrm{H_2N{-}CHR_1{-}CO{-}NH{-}CHR_2{-}COOH+H_2O} \]

说明：

  • 一条肽链中，连接两个氨基酸的化学键是肽键；
  • 每条肽链至少含有一个氨基和一个羧基；
  • n 个氨基酸形成 m 条肽链，脱去 n−m 个水，形成 n−m 个肽键；
  • 脱去水的个数 = 肽键个数 = 氨基酸个数（n）− 肽链数（m）；
  • 在脱去的水中，H 来自氨基和羧基，O 来自羧基。

2. 蛋白质的结构（B）

  • 氨基酸形成蛋白质的过程：氨基酸 \(\xrightarrow{\text{脱水缩合}}\) 多肽链 \(\xrightarrow{\text{盘曲折叠}}\) 蛋白质；
  • 蛋白质结构多样性的原因：组成蛋白质的氨基酸的种类、数目、排列顺序及多肽链的空间结构不同；
  • 说明：蛋白质结构多样性的根本原因是遗传物质 DNA 具有多样性。

3. 蛋白质的功能——生命活动的主要承担者（B）

  1. 构成细胞和生物体结构的重要物质，如肌动蛋白；
  2. 催化作用，如绝大多数酶是蛋白质（少数酶是 RNA）；
  3. 运输作用，如血红蛋白运输氧气、细胞膜上的载体蛋白；
  4. 调节作用，如胰岛素、生长激素；
  5. 防御作用，如抗体。

（二）分泌蛋白的合成、加工和运输

过程：核糖体（翻译合成蛋白质 / 肽链）→ 内质网（加工：折叠、组装、糖基化、运输，形成较成熟的蛋白质）→ 囊泡 → 高尔基体（加工：分类、运输，形成成熟的蛋白质）→ 囊泡 → 细胞膜（胞吐作用分泌出去）。整个过程由线粒体提供能量。

说明：该过程充分体现了生物膜在结构上具有流动性。

（三）几种细胞器的结构和功能

1. 叶绿体、线粒体的结构和功能（B）

（1）叶绿体：

  • 分布：主要在绿色植物的叶肉细胞内（注意：根细胞不含叶绿体）；
  • 结构：外膜、内膜；基粒（含与光合作用有关的色素和酶）；基质（含与光合作用有关的酶、DNA 等）；
  • 功能：进行光合作用的场所。

（2）线粒体：

  • 分布：除厌氧型生物外，普遍存在于真核细胞中；
  • 结构：外膜、内膜（含与有氧呼吸有关的酶等）；嵴（增大内膜面积）；基质（含与有氧呼吸有关的酶、DNA、RNA）；
  • 功能：进行有氧呼吸和形成 ATP 的主要场所（细胞胞基质也是细胞呼吸的场所）。

2. 其他几种细胞器的结构和功能（A）

  1. 内质网（单层膜）：是有机物的合成“车间”，蛋白质运输的通道；
  2. 高尔基体（单层膜）：动物细胞中与分泌物的形成有关，植物细胞中与有丝分裂时细胞壁的形成有关；
  3. 液泡（单层膜）：泡状结构，成熟的植物细胞中有大液泡；功能是贮藏（营养、色素等）、保持细胞形态、调节渗透吸水等；
  4. 核糖体（无膜结构）：合成蛋白质的场所；
  5. 中心体（无膜结构）：由垂直的两个中心粒构成，与动物细胞有丝分裂有关；
  6. 溶酶体（单层膜）：内含多种水解酶，能清除衰老、损伤的细胞器及侵入细胞的病毒、病菌等。

归纳：

  • 按膜的层数分类：无膜的细胞器——核糖体、中心体；单层膜的细胞器——内质网、高尔基体、液泡、溶酶体；双层膜的细胞器——线粒体、叶绿体；
  • 含有 DNA 的细胞器：线粒体、叶绿体；
  • 植物细胞特有的细胞器：叶绿体、液泡；动物细胞特有的细胞器：中心体（低等植物细胞也有）；
  • 能产生 ATP 的细胞器（与能量转换有关）：线粒体、叶绿体；
  • 参与分泌蛋白合成、加工和运输的细胞器：核糖体、内质网、高尔基体、线粒体（供能）。

（四）细胞核的结构和功能

1. 细胞核的结构和功能（B）

（1）结构：

  • 核膜：双层膜；
  • 核孔：细胞核与细胞质进行物质交换的通道，大分子如蛋白质或 mRNA 才能通过；
  • 染色质：易被碱性染料（如龙胆紫）染成深色；成分由 DNA 和蛋白质构成；与染色体是同一种物质在细胞不同时期的两种表现形态；
  • 核仁：与核糖体的形成和某种 RNA 合成有关。

（2）功能：①遗传信息库，储存和复制遗传物质 DNA 的主要场所；②细胞遗传和代谢的控制中心。

2. 原核细胞与真核细胞的区别与联系（B）

  • 分类依据：有无以核膜为界限的细胞核。
类别不同点相同点
真核有细胞核，有核膜，有染色体（由 DNA 和蛋白质构成），有多种细胞器都有细胞膜、细胞质、遗传物质 DNA 和核糖体
原核无细胞核（有拟核），无核膜，无染色体（有游离的 DNA），仅有一种细胞器——核糖体

常见的例子：

  • 真核生物：衣藻（绿藻）、草履虫、酵母菌、植物、动物；
  • 原核生物：蓝藻（蓝细菌）、细菌（大肠杆菌、硝化细菌、乳酸菌）；
  • 说明：病毒没有细胞结构，既不是真核生物也不是原核生物。

3. 细胞是一个有机的统一整体（B）

细胞的完整性是完成各项生命活动的前提条件。哺乳动物成熟的红细胞和精子，由于结构的不完整，它们的存活时间较短。

三、细胞的代谢 +

（一）物质进出细胞的方式

1. 物质跨膜运输方式的类型及特点（B）

物质跨膜运输方式运输方向是否需要载体是否消耗能量举例
被动运输自由扩散高→低（顺浓度）否否O₂、CO₂、水、甘油、脂肪酸、苯、乙醇、尿素等
协助扩散高→低（顺浓度）是否葡萄糖进入红细胞

转运蛋白分为载体蛋白和通道蛋白两种类型。

2. 大分子物质进出细胞的方式（A）

大分子和颗粒性物质通过内吞作用（胞吞）进入细胞，通过外排作用（胞吐）分泌出细胞外。该过程体现细胞膜的流动性，需要消耗 ATP。

3. 细胞膜是选择透过性膜（B）

（1）动物细胞的吸水和失水：外界溶液浓度 > 细胞质浓度，细胞失水皱缩；相等时细胞处于动态平衡，形态不变；外界溶液浓度 < 细胞质浓度，细胞吸水膨胀（甚至涨破）。

（2）植物细胞的吸水和失水：

  • 成熟植物细胞结构：细胞壁（全透性）；细胞膜、细胞质、液泡膜共同构成原生质层（具有选择透过性）；
  • 吸水和失水现象：外界溶液浓度 > 细胞液浓度，细胞失水，发生质壁分离；外界溶液浓度 < 细胞液浓度，细胞吸水，发生质壁分离复原。

（3）细胞膜是选择透过性膜：细胞膜和其他生物膜都是选择透过性膜，这些膜可以让小分子自由通过，细胞生命活动需要的一些离子和小分子也可以通过，其他的离子、小分子和大分子则不能通过。

（二）酶在代谢中的作用

1. 酶的本质、特性和作用（A）

  • 本质：酶是由活细胞产生的具有催化作用的一类特殊的有机物，绝大多数酶是蛋白质，少数酶是 RNA；
  • 特性：高效性、专一性、作用条件较温和（适宜的温度和 pH 等）；
  • 作用：催化作用，反应前后不变化，能显著降低化学反应的活化能。

2. 影响酶活性的因素（B）

影响酶促反应速率的因素有温度、pH、酶的浓度和底物的浓度等。

  • 温度：在最适温度下酶的活性最高；温度偏高或偏低，酶的活性都会明显降低。温度过高会使酶的空间结构遭到破坏，使酶永久失活；低温时酶的活性降低，但酶的空间结构仍保持稳定，恢复到适宜温度下酶的活性可以升高；
  • pH：在最适 pH 下酶的活性最高；pH 偏高或偏低，酶的活性都会明显降低；过酸或过碱会使酶的空间结构遭到破坏，使酶永久失活；
  • 说明：人体内酶的最适温度在 37 ℃ 左右；胃蛋白酶最适 pH 在 2 左右，胰蛋白酶最适 pH 在 8 左右。

（三）ATP 在能量代谢中的作用

1. ATP 的化学组成和结构特点（A）

  • 中文名：腺苷三磷酸；
  • 组成：腺苷（1 分子腺嘌呤 + 1 分子核糖）+ 3 个磷酸基团，含有两个特殊的化学键；
  • 结构简式：A—P~P~P（“~”表示特殊的化学键，A 代表腺苷，P 代表磷酸基团）；
  • 结构特点：ATP 中远离 A 的那个特殊化学键易水解，生成 ADP 和 Pi，并释放出大量能量，ATP 是一种高能磷酸化合物。

2. ATP 与 ADP 相互转化的过程及意义（B）

\[ \mathrm{ATP} \xrightleftharpoons[\text{酶}2]{\text{酶}1} \mathrm{ADP+Pi}+\text{能量} \]
  • 反应向右（ATP 水解）：右侧的能量来源于 ATP 分子中远离腺苷的特殊化学键，用于各项生命活动（如细胞分裂、物质的合成、植物根细胞吸收矿质元素、肌肉收缩等）；
  • 反应向左（ATP 合成）：右侧的能量来源于呼吸作用（有氧呼吸和无氧呼吸，人、动物和植物都有）、光合作用的光反应（仅植物有）等；
  • ATP 合成的场所（3 个）：细胞质基质、线粒体、叶绿体；
  • 意义：细胞中绝大多数需要能量的生命活动都是由 ATP 直接提供能量的；ATP 在细胞内的含量很少，转化快。

（四）光合作用以及对它的认识过程

1. 光合作用的认识过程（B）

  1. 1928 年：甲醛不能通过光合作用转化成糖；
  2. 希尔：离体叶绿体发生水光解，产生氧气；
  3. 恩吉（格）尔曼：光合作用的场所在叶绿体；
  4. 鲁宾和卡门（用放射性同位素标记法）：光合作用释放的氧全部来自参加反应的水；
  5. 阿尔农：在光照时，叶绿体中生成了 ATP，总是与水的光解相伴随；
  6. 卡尔文：用 ¹⁴C 标记的 CO₂ 追踪了光合作用过程中碳元素的行踪，即 ¹⁴CO₂ → ¹⁴C₃ →（¹⁴CH₂O）。

2. 光合作用的过程（B）

（1）定义：是绿色植物通过叶绿体，利用光能，把二氧化碳和水转化成储存能量的有机物，并且释放出氧气的过程。

（2）反应式：

\[ \mathrm{CO_2+H_2O} \xrightarrow[\text{叶绿体}]{\text{光能}} \mathrm{(CH_2O)+O_2} \]

（3）过程图解标号含义：①叶绿体类囊体薄膜；②O₂；③NADPH；④ATP；⑤C₃；⑥CO₂；⑦（CH₂O）。Ⅰ 光反应；Ⅱ 暗反应；Ⅲ 水的光解；Ⅳ CO₂ 的固定；Ⅴ C₃ 的还原。

（五）影响光合作用速率的环境因素

1. 环境因素对光合作用速率的影响（C）

  1. 光照：通过影响光反应中 ATP 和 [H] 的合成量，从而影响光合作用速率。在一定光照强度范围内，光合作用速率随光照强度增加而加快。A 点：无光，仅有细胞呼吸；B 点：光补偿点，光合作用速率等于呼吸作用速率；C 点：光饱和点，此时限制因素是 CO₂ 浓度、温度等；
  2. 外界 CO₂ 浓度：通过影响暗反应中 CO₂ 的固定，影响 C₃ 的合成量，从而影响光合作用速率；
  3. 温度：通过影响酶的活性，从而影响光合作用速率。在最适温度时光合作用速率最快，高于或低于最适温度速率下降；
  4. 土壤中的水分：通过影响叶气孔的开放度，影响 CO₂ 的供应，直接影响暗反应，间接影响光合作用速率。

2. 农业生产中提高农作物产量的方法（B）

  1. 延长光照时间，如补充人工光照、多季种植；
  2. 增加光照面积，如合理密植、套种；
  3. 增强光合作用效率：①光照强弱的控制——阳生植物（强光）、阴生植物（弱光）；②适当提高 CO₂ 浓度——施用农家肥、大棚使用干冰、温室与鸡舍猪舍相连等；③适当提高白天温度，降低夜间温度；④必需矿质元素的供应。

（六）细胞呼吸

1. 有氧呼吸和无氧呼吸过程及异同（B）

（1）有氧呼吸总反应式：

\[ \mathrm{C_6H_{12}O_6+6H_2O+6O_2} \xrightarrow{\text{酶}} \mathrm{6CO_2+12H_2O}+\text{能量} \]

有氧呼吸可分为 3 个阶段：

  1. 葡萄糖 → 丙酮酸 + [H] + 少量能量；场所：细胞质基质；
  2. 丙酮酸 + H₂O → [H] + CO₂ + 少量能量；场所：线粒体基质；
  3. [H] + O₂ → H₂O + 大量能量；场所：线粒体内膜。

（2）无氧呼吸总反应式（场所：细胞质基质）：

\[ \mathrm{C_6H_{12}O_6} \xrightarrow{\text{酶}} \mathrm{2C_3H_6O_3}+\text{（乳酸）少量能量} \] \[ \mathrm{C_6H_{12}O_6} \xrightarrow{\text{酶}} \mathrm{2C_2H_5OH+2CO_2}+\text{少量能量} \]

第一式见于人体肌细胞、乳酸菌等；第二式见于大多数植物细胞、酵母菌等。

（3）有氧呼吸和无氧呼吸的异同：

项目有氧呼吸无氧呼吸
场所细胞质基质、线粒体细胞质基质
是否需要氧气是否
最终产物CO₂、H₂O酒精和 CO₂ 或乳酸
释放能量的多少大量少量
联系第一阶段完全相同

说明：细胞呼吸产生的能量大多数以热能形式散失，小部分用于合成 ATP。

2. 细胞呼吸的意义及其在生产和生活中的应用（C）

  • 意义：细胞呼吸是生物体重要的代谢活动，不仅为生命活动提供能量，其中间产物（如丙酮酸等）还是各种有机物之间转化的枢纽；
  • 应用：①增加呼吸强度——农田松土、及时排涝；②抑制呼吸、减少有机物消耗——储藏瓜果蔬菜要低温、低氧、高 CO₂。
四、细胞的增殖 +

（一）细胞的生长和增殖的周期性（A）

1. 细胞的生长：多细胞生物的生长包括细胞体积的增大和细胞数目的增多。细胞体积增大是细胞生长的结果，随细胞体积增大，细胞对物质的交换效率相对降低；细胞数目增多是细胞分裂的结果，体细胞增殖的主要方式是有丝分裂。

2. 细胞增殖的周期性：进行连续分裂的细胞具有细胞周期，包括分裂间期和分裂期。分裂间期为物质准备期，大约占整个细胞周期的 90%，分裂期仅占 10% 左右。

（二）细胞的无丝分裂及其特点（A）

某些生物的部分体细胞可进行无丝分裂，如蛙的红细胞。无丝分裂的主要特点是没有出现纺锤体和染色体的变化，有 DNA 的复制。

说明：哺乳动物成熟的红细胞是不能分裂的，靠造血干细胞有丝分裂的方式补充红细胞。

（三）细胞的有丝分裂

1. 动、植物细胞有丝分裂过程及异同（B）

（1）分裂间期：主要完成 DNA 的复制和蛋白质的合成（动物细胞中心体复制）。结果：DNA 分子数加倍，染色体数不变（一条染色体含 2 条染色单体、2 个 DNA 分子）。

（2）动物细胞的有丝分裂：

  • 前期：染色质变为染色体，染色体散乱地排列；由中心体发出的星射线构成纺锤体；核膜解体、核仁消失；
  • 中期：每条染色体的着丝粒都排列在赤道板上（观察染色体的最佳时期）；
  • 后期：每条染色体的着丝粒分裂，姐妹染色单体分开，成为两条子染色体，并分别向细胞两极移动。此时染色体数加倍，DNA 分子数不变，染色单体消失；
  • 末期：染色体、纺锤体消失；核膜、核仁重现；细胞膜由中部向内凹陷，细胞质一分为二，细胞缢裂成两个子细胞。

（3）植物细胞的有丝分裂：

  • 前期：染色质变为染色体，染色体散乱地排列；由细胞两极发出的纺锤丝构成纺锤体；核膜解体、核仁逐渐消失；
  • 中期：每条染色体的着丝粒都排列在赤道板上（观察染色体的最佳时期）；
  • 后期：着丝粒分裂，姐妹染色单体分开成为两条子染色体，并分别向细胞两极移动；染色体数加倍，DNA 分子数不变，染色单体消失；
  • 末期：染色体、纺锤体消失；核膜、核仁重现；细胞中部出现细胞板，细胞板向四周扩展成为新的细胞壁（与高尔基体有关），最终细胞一分为二成为两个子细胞。

（4）动、植物细胞有丝分裂的比较：

项目植物细胞分裂动物细胞分裂
不同点间期无中心体中心体复制
前期细胞两极发出纺锤丝形成纺锤体中心体发出星射线形成纺锤体
末期细胞板（赤道板位置，与高尔基体有关）→ 细胞壁细胞膜从细胞中部向内凹陷缢裂
相同点分裂过程基本相同，染色体变化规律相同：分裂间期染色体复制；分裂期实现染色体平均分配到两个子细胞中去

2. 有丝分裂的特征和意义（B）

细胞增殖是生物体生长、发育、繁殖和遗传的基础。有丝分裂过程中染色体复制一次，细胞分裂一次，分裂结果是染色体平均分配到两个子细胞中去。子细胞具有和亲代细胞相同数目、相同形态的染色体，保证了亲代与子代的遗传性状的稳定性。

（四）细胞的分化

1. 细胞分化的意义及实例（A）

  • 意义：增加细胞的类型，使多细胞生物体中的细胞趋向专门化，有利于提高各种生理功能的效率；
  • 实例：造血干细胞经过细胞分裂增加细胞数目，通过细胞分化形成白细胞、红细胞和血小板等，执行不同的生理功能。

2. 细胞分化的过程及原因（B）

细胞分化过程中遗传信息不变，只是不同细胞中遗传信息的执行情况不同，即基因的选择性表达。

（五）细胞全能性的概念及实例（A）

  • 定义：细胞分裂分化后，仍具有产生发育成完整有机体或分化成其他各种细胞的潜能和特性；
  • 实例：植物组织培养和动物细胞核移植分别说明高度分化的植物细胞和动物细胞核具有全能性。

（六）细胞的衰老和凋亡与人体健康的关系

1. 细胞衰老的特征（A）

  1. 细胞内水分减少，细胞萎缩，代谢速率减慢；
  2. 细胞内有些酶的活性降低；
  3. 细胞内色素逐渐积累；
  4. 细胞呼吸速度减慢，细胞核体积增大，染色质固缩、染色加深；
  5. 细胞膜通透性功能改变，使物质运输能力降低。

2. 细胞的死亡（A）

  • 细胞凋亡：是细胞的一种重要的生命活动，是基因决定的细胞自动结束生命的过程，也称为细胞程序性死亡；
  • 细胞坏死：在种种不利因素影响下，由细胞正常代谢活动受损或中断引起的细胞损伤和死亡。

3. 细胞衰老和凋亡与人体健康的关系（A）

个体衰老与细胞衰老：对于单细胞生物来说，细胞的衰老就是个体的衰老；对于多细胞生物来说，个体衰老的过程是组成个体细胞普遍衰老的过程。

五、实验 +

（一）检测生物组织中的还原糖、脂肪和蛋白质

1. 实验原理（B）

  1. 还原糖（如单糖、麦芽糖、乳糖等）+ 斐林试剂（50～60 ℃ 水浴）→ 砖红色沉淀；
  2. 脂肪 + 苏丹Ⅲ染液 → 橘黄色；脂肪 + 苏丹Ⅳ染液 → 红色；
  3. 蛋白质 + 双缩脲试剂 → 紫色。

2. 实验材料用具、实验方法步骤（A）

（1）还原糖的检测：材料用具为还原糖含量较高、颜色为白色或近于白色的植物组织（或器官）；斐林试剂甲液（质量浓度 0.1 g/mL 的 NaOH 溶液）、乙液（质量浓度 0.05 g/mL 的 CuSO₄ 溶液）。步骤：①向试管内注入 2 mL 待测组织样液；②注入 1 mL 斐林试剂（甲乙液等量混合均匀后再加入）；③放入盛有 50～65 ℃ 温水的大烧杯中加热约 2 min；④观察颜色变化。

（2）脂肪的检测：材料用具为含脂肪量高、易做徒手切片的材料（如花生种子），苏丹Ⅲ或苏丹Ⅳ染液，体积分数 50% 的酒精溶液。步骤：切片（选最薄的几片薄片置于洁净载玻片中央）→ 染色（滴 2～3 滴苏丹Ⅲ染液，染色 2～3 min）→ 浮色（50% 酒精 1～2 滴）→ 制临时装片（滴 1～2 滴蒸馏水，加盖玻片）→ 镜检（先用低倍镜寻找观察点，再用高倍镜观察）。

（3）蛋白质的检测：材料用具为豆浆、鲜肝提取液、双缩脲试剂（A 液：0.1 g/mL 的 NaOH 溶液；B 液：0.01 g/mL 的 CuSO₄ 溶液）。步骤：①注入 2 mL 待测组织样液；②注入双缩脲试剂 A 液 1 mL，摇匀；③注入 B 液 4 滴，摇匀；④观察颜色变化。

3. 实验结果及其分析（C）

  • 还原糖：溶液由浅蓝色 → 棕色 → 砖红色沉淀，说明有还原糖存在；
  • 脂肪：显微镜视野中有橘黄色颗粒，说明有脂肪存在；
  • 蛋白质：溶液变为紫色，说明有蛋白质存在。

（二）观察植物细胞的质壁分离和复原

1. 实验原理（B）

  1. 成熟植物细胞的原生质层相当于一层半透膜，与外界溶液接触时能够发生渗透作用；
  2. 原生质层的伸缩性大于细胞壁。

渗透条件：①具有半透膜（原生质层）；②半透膜两侧溶液具有浓度差。细胞液浓度 < 外界溶液浓度 → 质壁分离；细胞液浓度 > 外界溶液浓度 → 质壁分离复原。

2. 实验材料用具、实验方法步骤（A）

材料用具：紫色洋葱鳞片叶外表皮、0.3 g/mL 的蔗糖溶液、清水、显微镜、载玻片、盖玻片等。

步骤：制作洋葱鳞片叶外表皮临时装片 → 用低倍显微镜观察（有一个紫色的中央大液泡，原生质层紧贴细胞壁）→ 盖玻片一侧滴 0.3 g/mL 蔗糖溶液、另一侧吸水纸吸引 → 低倍镜观察（中央液泡逐渐变小、颜色变深，原生质层与细胞壁逐渐分离）→ 再滴清水、吸水纸吸引 → 低倍镜观察（中央液泡逐渐变大、颜色变浅，原生质层逐渐贴近细胞壁）。

3. 实验结果及其分析（C）

  • 实验结果：植物细胞在 0.3 g/mL 蔗糖溶液中失水，液泡逐渐变小、颜色变深，发生质壁分离；置于清水中后吸水，液泡逐渐变大、颜色变浅，发生质壁分离复原；
  • 实验分析：①成熟的植物细胞有完整的渗透系统；②原生质层有选择透过性，细胞有活性；③能判断细胞液的浓度范围。

（三）探究影响酶活性的因素

1. 实验原理（B）

  1. 淀粉遇碘后形成蓝色的复合物；淀粉酶（α 淀粉酶最适温度 60 ℃）可以使淀粉逐步水解成麦芽糖和葡萄糖，麦芽糖和葡萄糖遇碘后不显色；
  2. 过氧化氢酶能催化 H₂O₂ 分解产生 O₂；根据产生气泡的速率或点燃但无火焰的卫生香复燃的剧烈程度，可以判断 H₂O₂ 分解的速率。

2. 实验设计（B）

（1）探究温度对淀粉酶活性的影响。材料用具：新鲜淀粉酶溶液、可溶性淀粉溶液、热水、冰块、碘液、试管、量筒、烧杯、酒精灯、石棉网、三脚架、火柴。步骤：①取 3 支洁净试管，编号 1、2、3，各注入 2 mL 可溶性淀粉溶液；②另取 3 支试管，各注入 1 mL 新鲜淀粉酶溶液；③将装有淀粉溶液和酶溶液的试管分成 3 组，分别放入热水（60 ℃，对照组）、沸水（实验组 1）、冰块（实验组 2）中，维持各自温度 5 min；④分别将淀粉酶溶液注入相同温度下的淀粉溶液中，摇匀，维持各自温度 5 min；⑤各滴入 1～2 滴碘液，摇匀；⑥观察颜色变化并记录。

（2）探究 pH 对过氧化氢酶活性的影响。材料用具：新鲜肝脏研磨液、H₂O₂ 溶液、盐酸溶液、NaOH 溶液、蒸馏水、试管、量筒、烧杯、酒精灯、石棉网、三脚架、火柴。步骤：①取 3 支洁净试管，编号 1、2、3，各注入 2 滴新鲜肝脏研磨液；②分别注入 1 mL 蒸馏水、盐酸溶液和 NaOH 溶液，摇匀；③各注入 2 mL H₂O₂ 溶液，用大拇指按住试管口，振荡试管；④观察哪支试管产生气泡的速率快，并记录结果。

3. 实验结果及其分析（C）

  • 温度对酶活性的影响：①本实验选用的酶不能是过氧化氢酶，因为加热也能促进过氧化氢分解，从而影响实验结果；②检测指标鉴定时不可使用斐林试剂，因为斐林试剂需水浴加热，低温组酶活性会升高，使一部分淀粉水解成麦芽糖，影响结果；③步骤中必须将淀粉溶液和淀粉酶溶液分别注入不同试管，先分成三组分别处理，不能先混合再分组；
  • pH 对酶活性的影响：①步骤①③不能颠倒，否则 H₂O₂ 溶液会稀释加入的酸或碱，结果可能不足以使过氧化氢酶失活；②本实验不可以用淀粉酶，因为酸也能促进淀粉水解，影响结果。

（四）绿叶中色素的提取和分离

1. 实验原理（B）

  1. 绿叶中的色素能溶解在有机溶剂无水乙醇（或丙酮）中，可提取绿叶中的色素；
  2. 色素在层析液中的溶解度不同，溶解度高的色素分子随层析液在滤纸条上扩散得快，溶解度低的扩散得慢，因而可用层析液将不同色素分离。

（五）探究酵母菌的呼吸方式

1. 实验原理（B）

  1. 酵母菌既能进行有氧呼吸，也能进行无氧呼吸；
  2. CO₂ 可使澄清的石灰水变浑浊，也可使溴麝香草酚蓝水溶液由蓝变绿再变黄；石灰水浑浊程度大、溴麝香草酚蓝变黄色时间越短，说明酵母菌产生的 CO₂ 越多，反之则越少；

（一）细胞的减数分裂过程

1. 减数分裂的概念（B）

减数分裂是进行有性生殖的生物在产生成熟生殖细胞时，进行的染色体数目减半的细胞分裂。在减数分裂过程中，染色体只复制一次，而细胞连续分裂两次。减数分裂的结果是成熟生殖细胞（精子或卵细胞）中的染色体数目比原始生殖细胞（精原或卵原细胞）减少一半。

2. 减数分裂的过程（B）

（1）染色体行为变化：染色体复制 → 同源染色体联会、形成四分体 → 同源染色体分离、非同源染色体自由组合 → 同源染色体分开，分别进入两个子细胞，细胞中染色体数减半，不存在同源染色体 → 染色体着丝点分裂，染色单体分开成为染色体，平均移向细胞两极 → 染色体平均分配到子细胞中。

（二）配子的形成过程

2. 配子的形成与生物个体发育的联系（B）

  • 有性生殖是由亲代产生有性生殖细胞或配子，经过两性生殖细胞（精子和卵细胞）的结合成为合子（如受精卵），再由合子发育成新个体的生殖方式；
  • 在有性生殖中，两性生殖细胞分别来自不同亲本，由合子发育成的后代具备了双亲的遗传特性，具有更强的生活能力和变异性，这对于生物的生存和进化具有重要意义。

（三）受精过程

1. 受精作用的过程（A）

  • 概念：指精子和卵细胞相互识别、融合成受精卵的过程；
  • 特点和意义：受精过程中精子的头部进入卵细胞，精子的细胞核与卵细胞的细胞核相融合，使彼此的染色体会合在一起，从而使受精卵中的染色体数目又恢复到体细胞的数目；
  • 说明：受精卵细胞核中的遗传物质（或染色体）一半来自精子、一半来自卵细胞；但受精卵细胞质中的遗传物质几乎全部来自卵细胞，即受精卵中来自母方的遗传物质略多于父方。

2. 减数分裂和受精作用对于生物遗传和变异的重要作用（B）

减数分裂和受精作用对于维持每种生物前后代体细胞中染色体数目的恒定，对于生物的遗传变异，都是十分重要的。

1. 肺炎双球菌的转化实验

（1）格里菲思的肺炎双球菌转化实验。肺炎双球菌有两种类型：S 型细菌——菌落光滑，菌体有荚膜，有毒性；R 型细菌——菌落粗糙，菌体无荚膜，无毒性。

实验过程：

  1. 第一组：注射 R 型活菌 → 小鼠不死亡；
  2. 第二组：注射 S 型活菌 → 小鼠死亡；
  3. 第三组：注射加热杀死的 S 型菌 → 小鼠不死亡；
  4. 第四组：注射加热杀死的 S 型菌和 R 型活菌的混合物 → 小鼠死亡，并在死亡小鼠体内分离到 S 型活菌。

推论：第四组实验中，已经被加热杀死的 S 型菌中含有“转化因子”，使 R 型菌转化为 S 型菌，但不清楚成分是什么。实验设计不足：未能将 DNA 与蛋白质分开，单独地直接地观察它们各自的作用。

（2）艾弗里的肺炎双球菌转化实验：第一组将 R 型细菌培养基与 S 型细菌的细胞提取物混合，培养基中出现 S 型细菌；第二至第四组分别加入蛋白酶（或 RNA 酶、酯酶等），培养基中仍出现 S 型细菌；第五组加入 DNA 酶，培养基中只长 R 型细菌。

实验结论：DNA 才是使 R 型细菌产生稳定遗传变化的物质（即 DNA 是遗传物质）。不足：提取的 DNA 中含有少量的蛋白质。

2. 噬菌体侵染细菌的实验

  • 研究者：赫尔希和蔡斯；
  • T₂ 噬菌体：①习性——寄生在大肠杆菌内的 DNA 病毒；②结构——外壳由蛋白质（含标志元素 S）组成，内部只有 DNA（含标志元素 P）；③同位素标记方法——先用分别含 ³⁵S 和 ³²P 的两种培养基培养大肠杆菌，制备分别含 ³⁵S 和 ³²P 的大肠杆菌，再用噬菌体分别侵染这两种细菌。

实验过程：

  1. 一组 T₂ 噬菌体的蛋白质外壳被 ³⁵S 标记，侵染未标记的大肠杆菌，经保温、搅拌、离心，结果上清液中放射性高、沉淀物中放射性低，说明 T₂ 噬菌体的蛋白质外壳没有进入细菌；
  2. 另一组 T₂ 噬菌体内部的 DNA 被 ³²P 标记，侵染未标记的大肠杆菌，经保温、搅拌、离心，结果上清液中放射性低、沉淀物中放射性高，说明 T₂ 噬菌体的 DNA 进入到细菌体内。

实验结论：DNA 是遗传物质。说明：本实验不能证明蛋白质不是遗传物质，原因是蛋白质未进入细菌体内。

（二）DNA 分子结构的主要特点（B）

  1. DNA 的组成元素：C、H、O、N、P；
  2. 基本组成单位：脱氧核糖核苷酸（4 种），由磷酸、脱氧核糖和碱基（A 腺嘌呤、T 胸腺嘧啶、C 胞嘧啶、G 鸟嘌呤）组成；
  3. DNA 分子结构主要特点：①由两条反向平行的脱氧核苷酸链盘旋成双螺旋结构；②外侧由脱氧核糖和磷酸交替连接构成基本骨架，内侧由氢键相连的碱基对组成；③碱基配对遵循碱基互补配对原则：A = T，G ≡ C。

（三）基因和遗传信息的关系

1. DNA 分子的多样性和特异性（B）

  • 多样性：碱基对的排列顺序千变万化，设 DNA 分子中有 n 对碱基，则有 4ⁿ 种 DNA；
  • 特异性：某种 DNA 具有特定的碱基对排列顺序。

2. DNA、基因和遗传信息（B）

基因是有遗传效应的 DNA 片段。一个 DNA 分子上有许多基因，基因的基本组成单位也是四种脱氧核糖核苷酸，基因中的碱基对排列顺序代表遗传信息。

（四）DNA 分子的复制

1. DNA 分子复制的过程及特点（B）

（1）过程：①解旋——利用细胞提供的能量，在解旋酶作用下把两条螺旋的双链解开；②以解开的每一条母链为模板，在 DNA 聚合酶等作用下，利用细胞中 4 种游离的脱氧核糖核苷酸为原料，按照碱基互补配对原则，各自合成与母链互补的一条子链；③每条子链与其对应的模板链盘旋成双螺旋结构，一个 DNA 分子形成两个完全相同的 DNA 分子。

（2）条件：①模板——亲代 DNA 分子的两条链；②原料——4 种游离的脱氧核糖核苷酸；③能量——ATP；④酶——解旋酶、DNA 聚合酶等。

（3）碱基互补配对原则：A—T、T—A、G—C、C—G。

（4）特点：①边解旋边复制；②半保留复制。

（5）DNA 双螺旋结构提供精确的模板，碱基互补配对保证复制的准确。

2. DNA 分子复制的实质及意义（B）

以亲代 DNA 为模板合成子代 DNA；DNA 分子通过复制将亲代的遗传信息传给子代，从而保证了遗传信息的连续性。

（五）遗传信息的转录和翻译（B）

1. RNA 的结构

  • 组成元素：C、H、O、N、P；
  • 基本组成单位：核糖核苷酸（4 种），碱基为 A、U（尿嘧啶）、C、G；
  • 结构：一般为单链。

2. RNA 的主要种类

  1. 信使 RNA（mRNA）：通过转录合成，直接控制蛋白质的合成。mRNA 上决定一个氨基酸的三个相邻碱基叫作一个密码子，密码子种类共有 4³（64）种，其中决定氨基酸的有 61 种，另三种是终止密码子；
  2. 转运 RNA（tRNA）：转运氨基酸，利用一端的三个碱基——反密码子识别氨基酸的密码子；
  3. 核糖体 RNA（rRNA）：构成核糖体的重要成分。

3. 基因控制蛋白质合成

（1）转录：

  • 概念：在细胞核中，以 DNA 的一条链为模板，按照碱基互补配对原则合成 RNA 的过程（叶绿体、线粒体中也会发生转录）；
  • 条件：模板——DNA 的一条链（模板链）；原料——4 种核糖核苷酸；能量——ATP；酶——RNA 聚合酶等；
  • 碱基互补配对原则：A—U、T—A、G—C、C—G；

（二）基因的分离规律和自由组合规律

1. 生物的性状及表现方式（A）

  • 相对性状：同一种生物的同一种性状的不同表现类型；
  • 显性性状：在杂种子一代中显现出来的性状，由显性基因控制；隐性性状：在杂种子一代中未显现出来的性状，由隐性基因控制；
  • 性状分离：在杂种后代中，同时出现显性性状和隐性性状的现象；
  • 表现型：生物个体表现出来的性状；基因型：与表现型有关的基因组成；
  • 基因型与表现型的关系：基因型决定表现型，表现型是基因型的表现形式；一般基因型相同，表现型一般相同，但表现型相同，基因型不一定相同；表现型是基因型和环境共同作用的结果。

2. 基因的分离规律（C）

（1）一对相对性状的杂交实验——发现问题：纯种高茎 × 纯种矮茎 → F₁ 全为高茎（显性性状）→ F₁ 自交 → F₂ 高茎 : 矮茎 = 3 : 1，出现性状分离现象。

（2）提出问题：由 F₁、F₂ 的现象分析，是什么原因导致 F₁ 表现一致，又是什么原因导致遗传性状在杂种后代中按一定比例分离。

（3）对分离现象的解释——提出假说：

  • 理论解释：生物的性状由遗传因子决定；体细胞中遗传因子成对存在；生物体在形成生殖细胞（配子）时，成对的遗传因子彼此分离，分别进入不同配子，配子中只含每对遗传因子中的一个；受精时雌雄配子的结合是随机的；
  • 遗传图解：P 高茎 DD × 矮茎 dd → 配子 D、d → F₁ Dd 高茎 → 自交 → F₂ 1DD : 2Dd : 1dd，即 3 高茎 : 1 矮茎。

（4）对分离现象解释的验证——演绎推理：

  • 方法：测交实验，即让 F₁ 与隐性纯合子杂交；
  • 遗传图解：杂种子一代高茎 Dd × 隐性纯合子矮茎 dd，配子 D、d 与 d 结合，测交后代 Dd 高茎 : dd 矮茎 = 1 : 1；
  • 预期：测交后代高茎和矮茎比例为 1 : 1；测交实验结果：高茎和矮茎比接近 1 : 1；
  • 结论：实验数据与理论分析相符，证明对分离现象的理论解释是正确的。

（5）分离规律——得出结论：

  • 研究对象：控制同一性状的遗传因子；时间：形成配子时；行为：成对的遗传因子发生分离；结果：分离后的遗传因子分别进入不同配子中，随配子遗传给后代；
  • 实质：减数分裂形成配子时，等位基因随同源染色体的分开而分离。

说明：孟德尔采用的是遗传因子，而不是基因这一概念。

3. 基因的自由组合规律（B）

（1）两对相对性状的杂交实验——发现问题：P 黄色圆粒 × 绿色皱粒 → F₁ 黄色圆粒 → F₂ 黄圆 : 绿圆 : 黄皱 : 绿皱 = 9 : 3 : 3 : 1。F₁ 全为黄色圆粒，表明粒色中黄色是显性、粒形中圆粒是显性；F₂ 中出现了不同性状之间的重新组合。

（2）对自由组合现象的解释——提出假说：

  • 理论解释：两对相对性状分别由两对遗传因子控制；F₁ 产生配子时，每对遗传因子彼此分离，不同对的遗传因子可以自由组合；F₁ 产生配子种类及比例：YR : Yr : yR : yr = 1 : 1 : 1 : 1；受精时雌雄配子结合是随机的，配子结合方式为 16 种；
  • 遗传图解：P 黄圆 YYRR × 绿皱 yyrr → 配子 YR、yr → F₁ 黄圆 YyRr → 自交 → F₂ 黄圆 Y_R_ 9/16、黄皱 Y_rr 3/16、绿圆 yyR_ 3/16、绿皱 yyrr 1/16。

（3）对自由组合现象解释的验证——演绎推理：方法为测交实验。P 黄色圆粒 YyRr × 绿色皱粒 yyrr，配子 YR、Yr、yR、yr 与 yr 结合，子代 YyRr 黄圆 : Yyrr 黄皱 : yyRr 绿圆 : yyrr 绿皱 = 1 : 1 : 1 : 1。

（4）自由组合规律——得出结论：

  • 内容：控制不同性状的遗传因子的分离和组合是互不干扰的；在形成配子时，控制同一性状的成对遗传因子彼此分离，控制不同性状的遗传因子自由组合；
  • 实质：减数第一次分裂后期，非同源染色体上的非等位基因自由组合。

1. 伴性遗传及其特点（B）

性染色体上的基因决定的性状，在遗传上总是和性别相关联，这类遗传被称为伴性遗传；该类性状的遗传往往在不同性别间表现存在差异。

2. 常见几种遗传病及其特点（B）

1. 基因突变的概念、原因、特征（B）

  • 概念：指 DNA 分子中发生碱基对的替换、增添和缺失，而引起的基因结构的改变；
  • 原因：①物理因素——紫外线、X 射线及其他辐射损伤细胞内的 DNA；②化学因素——亚硝酸、碱基类似物等能改变核酸的碱基；③生物因素——某些病毒的遗传物质能影响宿主细胞的 DNA；
  • 特征：①普遍性；②随机性；③不定向性；④低频率性；⑤多害少利性。

2. 癌细胞的主要特征：（1）能无限增殖；（2）形态结构发生显著变化；（3）细胞膜上糖蛋白减少，黏着性显著降低，容易在体内分散和转移。

6. 基因突变的意义（A）：（1）是新基因产生的途径；（2）是生物变异的根本来源；（3）是生物进化的原始材料；（4）是形成生物多样性的重要原因之一。

（三）染色体结构变异和数目变异（A）

1. 染色体结构变异：

  • 实例：猫叫综合征（5 号染色体部分缺失）；
  • 类型：缺失、重复、倒位、易位；
  • 遗传学效应：染色体上基因的数目或排列顺序改变（基因本身未发生改变）。

2. 染色体数目的变异：

  • 类型：①个别染色体增加或减少，如 21 三体综合征；②以染色体组的形式成倍增加或减少，如三倍体无子西瓜；
  • 染色体组：概念——细胞中的一组非同源染色体，在形态和功能上各不相同，携带着控制生物生长发育的全部遗传信息，这样的一组染色体叫一个染色体组；特点——一个染色体组中无同源染色体，形态和功能各不相同，一个染色体组携带着控制生物生长发育所需的全部遗传信息。

3. 单倍体、二倍体和多倍体：

  • 由配子发育成的个体叫单倍体（不管含有几个染色体组）；
  • 由受精卵发育成的个体，含两个染色体组的叫二倍体；含三个或三个以上染色体组的叫多倍体。如普通小麦是六倍体，而通过花药离体培养得到的个体含 3 个染色体组，为单倍体。

（四）生物变异在育种上的作用

1. 杂交育种在生产中的应用（B）

  • 概念：指利用杂交手段使同种生物不同的优良性状重新组合，集中在同一个体上表现；
  • 原理：基因重组；优点：操作简便，目的性较强，可培养优势杂种；
  • 实例：杂交水稻、矮秆抗病小麦的培育。

2. 诱变育种在生产中的应用（A）

  • 概念：指利用物理因素（如 X 射线、γ 射线、紫外线、激光等）或化学因素（如亚硝酸、硫酸二乙酯等）处理生物，使生物发生基因突变；
  • 原理：基因突变；优缺点：可以提高突变率，加速育种进程，大幅度地改良性状，但有利变异个体少；
  • 实例：“黑农五号”大豆新品种的培育；青霉素高产菌株的培育。

3. 多倍体育种的原理、方法及特点（A）

  • 原理：染色体变异；方法：用秋水仙素处理萌发的种子或幼苗；
  • 原理：秋水仙素能够抑制纺锤体的形成，导致染色体不分离，细胞内染色体数目加倍；
  • 优缺点：培育出的植物器官大、产量高、营养丰富，但结实率低、成熟迟；
  • 实例：三倍体无子西瓜、小黑麦的培育。

4. 单倍体育种的原理、方法及特点（A）

  • 原理：染色体变异；方法：花药（粉）离体培养；
  • 特点：明显缩短育种年限，但技术较复杂；
  • 实例：矮秆抗病水稻的培育。

六、生物的进化

（一）现代生物进化理论的主要内容（B）

  1. 适应是自然选择的结果，种群是生物进化的基本单位；
  2. 生物进化的实质是种群基因频率的改变；
  3. 突变和基因重组产生进化的原材料。说明：基因突变和染色体变异统称为突变；
  4. 自然选择决定生物进化的方向；
  5. 隔离导致新物种的形成，是物种形成的必要条件；
  6. 协同进化形成生物多样性。

关于物种与隔离：

  • 物种的概念：能够在自然状态下相互交配并且产生可育后代的一群生物；
  • 隔离的概念：不同种群间的个体，在自然条件下基因不能自由交流的现象；
  • 隔离的类型：常见的有地理隔离和生殖隔离，生殖隔离是产生新物种的标志；
  • 新物种形成机制：变异、选择和隔离是物种形成的三个环节。物种形成的常见方式是经过长期的地理隔离进而产生生殖隔离，但并非所有新物种的形成都要经过长期的地理隔离才产生生殖隔离。

（二）生物进化与生物多样性的形成

1. 生物进化的历程（A）

  • 地球上的生物是从单细胞到多细胞、从简单到复杂、从水生到陆生、从低级到高级逐渐进化而来的，化石是研究生物最直接、最重要的证据；
  • 真核细胞出现后，出现了有丝分裂和减数分裂，从而出现了有性生殖，使基因重组产生的变异量大大增加，所以生物进化的速度大大加快。

2. 生物多样性形成的原因（B）

生物多样性主要包括基因（遗传）多样性、物种多样性和生态系统多样性；生物多样性是生物与生物、生物与环境相互作用、协同进化的结果。

七、实验：调查人群中的遗传病

1. 调查的方法和过程（A）

  1. 选取群体中发病率较高的单基因遗传病进行调查，如红绿色盲、白化病、高度近视等；
  2. 调查某种遗传病的发病率，需保证被调查的群体足够大，小组调查的数据应在班级和年级中汇总，同时应做到随机取样；
  3. 调查某种遗传病的遗传方式，应以患者家系为单位进行逐个调查，不仅要记录家系各成员的性状表现，还要记录各成员的性别和成员之间的血缘关系；
  4. 要注意保护被调查人的隐私。

2. 调查的结果及其分析（C）

（1）遗传病发病率的计算：

\[ \text{某种遗传病发病率}=\frac{\text{某遗传病的患病人数}}{\text{被调查总人数}}\times100\% \]

2. 植物体细胞杂交（植物细胞融合）

流程：植物细胞 A、植物细胞 B → 酶解（纤维素酶、果胶酶分解细胞壁）→ 原生质体 A、原生质体 B → 人工诱导融合 → 融合的原生质体 → 再生细胞壁，形成杂种细胞 → 植物组织培养 → 杂种植株。

诱导方法：物理法（离心、振动、电激）、化学法（聚乙二醇 PEG）。

（二）动物细胞工程

1. 动物细胞培养

  • 原理：细胞增殖；
  • 培养基：液体培养基，含营养物质、葡萄糖、动物血清、动物血浆等；
  • 过程：取动物组织 → 制成细胞悬液 → 原代培养 → 分瓶 → 传代培养。

2. 动物细胞融合技术

  1. 概念：使两个或多个动物细胞结合形成一个细胞的过程；
  2. 诱导方法：物理法（电激法）、化学法（聚乙二醇 PEG 融合法）、生物法（灭活病毒诱导法）；
  3. 结果：形成单核细胞；
  4. 意义：突破了有性杂交的局限，使远缘杂交成为可能。
